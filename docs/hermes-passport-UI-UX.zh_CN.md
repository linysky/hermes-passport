# hermes-passport UI/UX 设计

**[简体中文](hermes-passport-UI-UX.zh_CN.md)** | [English](hermes-passport-UI-UX.md)

目标硬件：**FoloToy AI Passport** —— ESP32-C3，ST7789P3 240×320 竖屏 RGB565，3 按键
（`UP` / `DOWN` / `OK`，共用 GPIO0 ADC 电阻分压），ES8311 音频，CW2017 电量计。

设计意图沿用 `ai-passport-hermes` 已验证的产品定义：
**工牌回答的是「Agent 在干什么、干完了没有、有没有事需要我拍板」——而此时人不在电脑前。**
所以显示摘要，不显示全文。

---

## 1. 设计原则

| # | 原则 | 推论 |
|---|---|---|
| 1 | **只给摘要，永不给全文** | BLE 无确认写入会丢片段，长报文整条丢失。单屏 ≤ 约 170 汉字。 |
| 2 | **一根拇指、三个键** | 每个状态都必须能只用 UP/DOWN/OK 操作，核心动作不许用组合键。 |
| 3 | **两秒可读** | Hero 布局只给「一行标题 + 一行细节」。戴的人是边走边看的。 |
| 4 | **拍板优先** | Hermes 需要审批时，工牌接管屏幕，一键确认。 |
| 5 | **默认安静** | 中性灰阶。彩色只用于**语义**信号（录音、错误、决策）。 |
| 6 | **破坏性操作必须长按** | 重置 / 忘记配对 / 新会话一律 2 秒长按，绝不单击触发。 |

## 2. 配色

冷灰单色，与 Hermes 桌面端主题一致。颜色只承载语义。

| Token | Hex | 用途 |
|---|---|---|
| `COLOR_BG` | `#080A0C` | 屏幕底色 |
| `COLOR_PANEL` | `#1A1D21` | 卡片 / 消息面板 |
| `COLOR_TEXT` | `#F2F4F6` | 正文 |
| `COLOR_TEXT_DIM` | `#8B9198` | 提示、时间、页码 |
| `COLOR_ACCENT` | `#C3C7CC` | 选中行、焦点条 |
| `COLOR_RECORD` | `#D97757` | **仅**录音指示 |
| `COLOR_WARN` | `#C9A227` | **仅**决策提示、低电量 |
| `COLOR_ERROR` | `#B54A4A` | **仅**错误态 |

字体（LVGL 9，在 `sdkconfig.defaults` 启用）：

| 角色 | 字体 | 字号 |
|---|---|---|
| 状态栏 | `lv_font_montserrat_12` | 12 px |
| 提示栏 | `lv_font_montserrat_12` | 12 px |
| 正文 / 摘要 | `lv_font_unscii_8` + CJK 回退 | 行高 16 px（基线步进实测 21 px） |
| 标题 | `lv_font_montserrat_20` | 20 px |

> 中文正文用生成的 16 px CJK 字体；纯英文的界面框架用 Montserrat。

## 3. 屏幕结构（所有状态通用）

```
┌──────────────────────────────┐  y=0
│ BLE▲  10:24        ▮▮▮▯  82% │  状态栏   20 px
├──────────────────────────────┤  y=20
│                              │
│           内容区             │  240 × 280 px
│                              │
│                              │
├──────────────────────────────┤  y=300
│ OK 说话 · ▲ 首页 · 长按 菜单  │  提示栏   20 px
└──────────────────────────────┘  y=320
```

- **状态栏**（20 px）：BLE 连接图标（亮＝已连接，中灰＝广播中）、时钟、电池格。
- **内容区**（280 px）：按状态走 hero 布局或文本布局。
- **提示栏**（20 px）：固定一行，**随时**告诉用户每个键此刻的作用。

## 4. 各屏设计

### 4.1 首页（HOME）—— hero 布局

```
┌──────────────────────────────┐
│ BLE▲  10:24        ▮▮▮▯  82% │
│                              │
│                              │
│          ┌────────┐          │
│          │        │          │
│          │ NOUS   │          │
│          │  GIRL  │          │
│          │180×180 │          │
│          └────────┘          │
│                              │
│      Hi, I'm Hermes         │  标题（20 px）
│      点 OK 开始说话           │  细节（16 px，暗色）
│                              │
├──────────────────────────────┤
│ OK 说话 · ▲ 首页 · 长按 菜单  │
└──────────────────────────────┘
```

- 吉祥物：180×180，2-bit 调色板索引（4 级灰）—— 由官方 Nous Girl SVG 4× 超采样生成。
- 一轮对话结束后显示**上一条回复标题**；闲置 20 秒回到 "Hi, I'm Hermes"。

### 4.2 摘要页（SUMMARY）—— 主工作屏

```
┌──────────────────────────────┐
│ BLE▲  10:24        ▮▮▮▯  82% │
│ 明天里斯本天气          [3/7] │  标题 + 页码
├──────────────────────────────┤
│ 明天多云转晴，18~25°C，       │
│ 东风 3 级。适合户外，但早晚   │
│ 温差大，建议带件外套。        │
│                              │
│ 来源：天气查询工具            │  暗色
│                              │
│ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─  │  分隔线
│ ▸ 上一条：已备份 NAS  10:12   │  历史预览
├──────────────────────────────┤
│ ▲↓滚动 ▼翻页 · OK 说话        │
└──────────────────────────────┘
```

- 正文**按字符断行**（中文没有空格）。宽度按完整字符量。
- **避头尾**：行首不出现收尾标点。做法是把当前行末字留给下一行 —— 而**不是**超宽硬塞（渲染层会裁掉越界内容，标点会连同前一个字一起消失）。
- 页码 `[n/m]` 在右上；长回复闲置时约每秒自动翻一行。

### 4.3 历史页（HISTORY）—— 最近 10 条环形缓冲

```
┌──────────────────────────────┐
│ BLE▲  10:24        ▮▮▮▯  82% │
│ 历史                    [2/10]│
├──────────────────────────────┤
│ ▸ 明天里斯本天气      10:24   │  ← 选中（accent 条）
│   已备份 NAS          10:12   │
│   PR #42 已合并        09:58  │
│   部署完成             09:31  │
│   磁盘告警已解除        08:47  │
│                              │
├──────────────────────────────┤
│ ▲▼ 选择 · OK 查看 · 长按 返回 │
└──────────────────────────────┘
```

- 环形缓冲，最新在前。同一条回复不会占两个槽位。
- 设备侧历史只在内存里；桥**每次重连重放最近 10 条**。

### 4.4 录音页（RECORDING）

```
┌──────────────────────────────┐
│ BLE▲  10:24        ▮▮▮▯  82% │
│                              │
│                              │
│            ●●●               │  录音点（COLOR_RECORD）
│                              │
│       正在听… (0:03)          │
│                              │
│      ████████████████        │  实时电平表（16 格）
│      ▁▂▅▇█▇▅▂▁▂▅▇█▇▅        │
│                              │
├──────────────────────────────┤
│ OK 停止 · 长按 OK 取消        │
└──────────────────────────────┘
```

- 最长 30 秒，到时自动停止。
- 电平表取最近 16 个 RMS 块（每块 32 ms）。
- 按下不足 350 ms 视为误触，丢弃。

### 4.5 转写确认页（TRANSCRIBE）

```
┌──────────────────────────────┐
│ BLE▲  10:24        ▮▮▮▯  82% │
│ 转写确认                 [1/2]│
├──────────────────────────────┤
│ 请帮我查一下明天里斯本的      │
│ 天气，顺便看看要不要带伞。    │
│                              │
│        ～ 换行继续 ～          │
│                              │
├──────────────────────────────┤
│ ▲ 重发 · ▼ 翻页 · OK 发送     │
└──────────────────────────────┘
```

- 用户确认 Hermes 听到了什么，再进会话。
- `UP` = 重录，`DOWN` = 长转写翻页，`OK` = 发送。

### 4.6 决策页（DECISION）—— 审批接管屏幕

```
┌──────────────────────────────┐
│ BLE▲  10:24        ▮▮▮▯  82% │
│ ⚠ 需要你拍板                  │
├──────────────────────────────┤
│                              │
│   允许执行这个命令？          │
│                              │
│   git push --force           │  等宽字体，面板底
│                              │
│   目标：production           │  暗色细节
│                              │
│                              │
│         ┌──────┐             │
│         │ 确认 │  ← OK       │
│         └──────┘             │
│         ┌──────┐             │
│         │ 拒绝 │  ← 长按 OK   │
│         └──────┘             │
├──────────────────────────────┤
│ OK 确认 · 长按 OK 拒绝        │
└──────────────────────────────┘
```

- 覆盖：危险 shell 命令、`/new`、模型切换、Hermes 任何要求确认的动作。
- 提示**排队**，一次一个，按到达顺序。离线时收到的提示在重连时显示。
- 超时后工牌显示「该问题已过期」。

### 4.7 菜单 / 设置

```
┌──────────────────────────────┐
│ BLE▲  10:24        ▮▮▮▯  82% │
│ 设置                          │
├──────────────────────────────┤
│ ▸ 亮度          ████████░░ 80│
│   背光              开        │
│   音量          █████░░░░░ 45│
│   播报              开        │
│   提示音            开        │
│   蓝牙              开        │
│   息屏              立即      │
│   重置              …        │
├──────────────────────────────┤
│ ▲▼ 选择 · OK 调节 · 长按 返回 │
└──────────────────────────────┘
```

| 项目 | 取值 | 存 NVS |
|---|---|---|
| 亮度 | 10–100 % | 是 |
| 背光 | 开 / 关（关＝息屏） | 是 |
| 音量 | 0–100 % | 是 |
| 播报 | 开 / 关（语音念要点） | 是 |
| 提示音 | 开 / 关 | 是 |
| 蓝牙 | 开 / 关 | 是 |
| 息屏 | 立即 / 30 s / 60 s / 关 | 是 |
| 重置 | 恢复出厂（**长按确认**） | — |

- 开机从 NVS 应用。`OK` 循环/步进取值；`长按 UP/DOWN` 跳到最小/最大。
- 「播报 / 提示音」两个开关与桥侧真值**双向同步**（真值在桥，设备只是遥控器）。

### 4.8 息屏（SLEEP）

```
┌──────────────────────────────┐
│                              │
│          (全黑)              │
│                              │
│                              │
└──────────────────────────────┘
```

- 只关背光。CPU、BLE、音频照常运行。
- 任意键唤醒。**唤醒那一下只点亮，不做别的** —— 不会误触发动作。

## 6. 交互表（按键 × 状态）

| 状态 | `UP` 单击 | `UP` 长按 | `DOWN` 单击 | `DOWN` 长按 | `OK` 单击 | `OK` 长按 |
|---|---|---|---|---|---|---|
| **HOME** | 上滚（到标题） | **MENU** | 打开 HISTORY | — | 开始 RECORDING | **新会话**（2 s 确认） |
| **SUMMARY** | 正文上滚一行 | HOME | 下一条历史 | HISTORY | 开始 RECORDING | 新会话（2 s 确认） |
| **HISTORY** | 选中上一条 | HOME | 选中下一条 | SUMMARY | 打开 SUMMARY | HOME |
| **RECORDING** | — | — | — | — | 停止 → TRANSCRIBE | **取消**（丢弃录音） |
| **TRANSCRIBE** | 重录 | — | 转写翻页 | — | 发送 → HOME | 重录 |
| **DECISION** | — | — | — | — | **确认** | **拒绝** |
| **MENU** | 上一项 / 值 − | HOME | 下一项 / 值 + | — | 步进 / 切换取值 | HOME |
| **SLEEP** | 唤醒 | 唤醒 | 唤醒 | 唤醒 | 唤醒 | 唤醒 |

**规则**

1. 长按永远做**更安全**的事（取消、拒绝、返回）。
2. 任何状态都不需要同时按两个键。
3. 每个状态的提示栏都重述映射 —— 用户永远不用记。

## 7. 状态栏图例

| 图标 | 含义 |
|---|---|
| `BLE▲` 亮 | 已连接且已配对 |
| `BLE▲` 中灰 | 广播中，未连接 |
| `BLE▲` 暗 | 蓝牙关闭 |
| `▮▮▮▯` + `%` | CW2017 电量格；**读数缺失时整块不画** |
| `⚠`（COLOR_WARN） | 低电量（< 15 %），或有待处理决策 |
| `●`（COLOR_RECORD） | 录音中 |

## 8. 提示音（ES8311，可关）

| 事件 | 节奏 | 频率 |
|---|---|---|
| 思考 / 干活中 | 每 3 秒一声短滴 | 880 Hz |
| 开始录音 | 一声 | 1760 Hz |
| 停止录音 | 两声 | 1760 Hz |
| 有待决策 | 一声上行 | 660→1320 Hz |

全部受「提示音」设置控制。静音模式下仍保留视觉指示。

---

## 9. 无障碍 / 约束

- 正文基线步进实测 **21 px**，不是 10 px —— 滚动上限必须用实测值。
- 换行后输出缓冲需要 **768 B**（输入 512 B），因为换行会插入 `\n`。
- 单条摘要文本缓冲预算 **512 B**（约 170 汉字）。前人实测把它提到 3 KB 以上再加历史 RAM
  会导致 C3（无 PSRAM）**静默停止 BLE 广播** —— 保持小。
- 音频：按 512 采样块（1 KB）录音。绝不缓冲超过 3 秒的完整录音。
